# Usage Guide

This guide provides instructions on how to use the Flashcard Automation application.

## Getting Started

1.  **Download the Application**: Download the latest version of the application for your operating system.
2.  **Install**: Follow the installation instructions for your platform.
3.  **Launch**: Open the application to get started.

## Features

-   **CSV Processing**: Import flashcards from a `.csv` file.
-   **Facebook Integration**: Connect your Facebook account to post to your pages.
-   **Scheduled Comments**: Schedule comments to be posted at a later time.
-   **Dry Run Mode**: Preview your posts before they go live.
