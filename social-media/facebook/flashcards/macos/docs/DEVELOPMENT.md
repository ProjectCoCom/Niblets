# macOS Development Guide

This guide provides specific instructions for developing the Flashcard Automation application on macOS.

## Environment Setup

-   **Xcode**: Ensure you have the latest version of Xcode installed from the Mac App Store.
-   **Swift Package Manager**: The project uses Swift Package Manager for dependencies.

## Building and Running

1.  **Open in Xcode**: Open the `Package.swift` file located in `social-media/facebook/flashcards/macos/FlashcardAutomation` to open the project in Xcode.
2.  **Select Target**: Select the `FlashcardAutomation` executable target and a macOS run destination.
3.  **Run**: Click the "Run" button in Xcode to build and run the application.

## Testing

Run the tests by navigating to the "Test" navigator in Xcode and running the test suite.
