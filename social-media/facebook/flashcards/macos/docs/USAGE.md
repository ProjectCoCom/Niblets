# macOS Usage Guide

This guide provides specific instructions for using the Flashcard Automation application on macOS.

## Installation

1.  **Download**: Download the `FlashcardAutomation.dmg` file.
2.  **Mount**: Double-click the `.dmg` file to mount it.
3.  **Install**: Drag the `FlashcardAutomation` application to your `Applications` folder.

## System Requirements

-   **macOS**: macOS 12.0 or later.
-   **Architecture**: Apple Silicon (ARM64).
